Control de humedad y temperatura en invernaderos

Nuestro proyecto se basa en la implementación de un sistema de control de humedad y temperatura de un invernadero mediante el uso de un sensor DHT11, el cual se encargará del sensado de los parámetros. A través de nuestro microcontrolador guardaremos y compararemos los mismos con los definidos anteriormente, los cuales podrán ser modificados en tiempo real según requerimientos del operador.

En caso de que la medición indique que hay que regular algún parámetro se hará uso de un ventilador o una luz para la temperatura y un pequeño sistema de riego para la humedad, de esta forma mantendremos el ecosistema en las condiciones óptimas indicadas. A su vez, en caso de requerir una revisión manual, el sistema tiene una memoria la cuál contendrá las últimas 10 mediciones realizadas con un intervalo de muestreo de 2 segundos, que luego el sistema entregará al trabajador para su control.
